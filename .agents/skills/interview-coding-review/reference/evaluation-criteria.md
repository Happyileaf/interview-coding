# 面试编程题评价标准

## 正确性

只有两种结果：
- **正确**：代码能够正确解决问题，通过所有测试用例
- **错误**：代码存在 bug 或无法通过部分/全部测试用例

## 还原度

三种结果，按照匹配程度从高到低：

1. **逐字符还原**：代码和标准答案逐字符完全一致（包括变量名、空格、换行等）
2. **逻辑一致**：算法逻辑和思路完全一致，但实现细节（如变量名、写法）有差异，功能正确
3. **功能正确**：功能实现正确，但整体思路和实现方式差异较大

## 分析维度

对于每个对比文件，需要分析：
1. **算法思路对比**：对比用户解答和标准答案的思路差异
2. **实现差异**：列出具体的代码实现差异点
3. **复杂度对比**：对比时间复杂度和空间复杂度
4. **问题检查**：列出用户代码中发现的问题，如果没有问题说明"没有发现问题"
5. **评价与建议**：给出总体评价和优化建议
