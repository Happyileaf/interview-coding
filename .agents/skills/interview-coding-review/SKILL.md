# Interview Coding Review

这个技能用于面试编程题练习后的自动化检查对比流程。

## 使用场景

当用户完成一道面试编程题练习后，需要对比标准答案、检查错误、分析差异和获取评价时，调用此技能。

## 工作流程

### 阶段一：确认对比文件范围
1. 自动查找 Git 工作区中修改过的带 `copy` 后缀的文件，识别所有用户练习文件
2. 对每个练习文件，根据练习文件名推断原始标准答案文件路径（去除 `copy` 后缀）
3. 验证原始文件是否存在，收集所有匹配成功的文件对
4. 如果没有找到任何匹配的文件对，再询问用户确认用户解答文件和标准答案文件路径

### 阶段二：对比分析处理
1. 对所有确认好的文件对，逐个处理
2. 读取两个文件的内容
3. 对比分析每个文件对：
   - 算法思路是否一致
   - 实现方式差异
   - 时间/空间复杂度对比
   - 可能存在的 bug 或边界问题
   - 代码风格和可读性评价
   - 优化建议

### 阶段三：输出结果
1. 读取评价标准和报告模板
2. 严格遵循评价标准中的定义进行判定
3. 汇总所有文件的对比分析结果
4. 按照模板格式输出结构化的分析报告

## 引用文件

- `reference/evaluation-criteria.md` - 定义了正确性和还原度的评价标准
- `reference/report-template.md` - 分析报告的输出模板

## 约束

- 仓库结构：标准答案都在仓库各文件中，用户在练习时复制出同名文件并添加 `copy` 后缀进行还原练习
- 支持一次处理多个文件，批量对比 review
- 技能只负责对比分析，不修改原有代码
