# Interview Coding Review

## 概述
这个技能用于面试编程题练习后的自动化检查对比流程，负责对比用户解答与标准答案，分析差异并给出评价和建议。

## 使用场景
当用户完成一道面试编程题练习后，需要对比标准答案、检查错误、分析差异和获取评价时，调用此技能。

## 输入
1. 自动查找模式：通过 Git 工作区中修改过的带 `copy` 后缀的文件自动识别用户练习文件
2. 手动确认模式：如果自动查找失败，需要用户提供用户解答文件路径和标准答案文件路径
3. 支持一次输入多个文件对，进行批量处理

## 工作流程
### 阶段一：确认对比文件范围
1. 自动查找 Git 工作区中修改过的带 `copy` 后缀的文件，识别所有用户练习文件
2. 对每个练习文件，根据练习文件名推断原始标准答案文件路径（去除 `copy` 后缀）
3. 验证原始文件是否存在，收集所有匹配成功的文件对
4. 如果没有找到任何匹配的文件对，询问用户确认用户解答文件和标准答案文件路径

### 阶段二：对比分析处理
1. 对所有确认好的文件对，逐个处理
2. 读取用户解答文件和标准答案文件的内容
3. 对比分析每个文件对，覆盖以下维度：
   - 算法思路是否一致
   - 实现方式差异
   - 时间/空间复杂度对比
   - 可能存在的 bug 或边界问题
   - 代码风格和可读性评价
   - 优化建议

### 阶段三：输出结果
1. 读取评价标准和报告模板
2. 严格遵循评价标准中的定义进行判定
3. 汇总所有文件的对比分析结果
4. 按照模板格式输出结构化的分析报告

## 执行规则
1. 必须先完成文件匹配确认，再进行对比分析
2. 必须从 `reference/evaluation-criteria.md` 读取评价标准，并严格按照标准判定
3. 必须按照 `reference/report-template.md` 的模板格式输出结果
4. 支持批量处理多个文件对，逐个分析后汇总输出

## 输出
按照报告模板输出结构化的分析报告，包含：
- 每个文件对的对比分析结果
- 算法思路对比
- 实现差异分析
- 复杂度对比
- 问题识别（bug/边界问题）
- 代码风格评价
- 优化建议
- 总体正确性和还原度评价

## 约束
- 仓库结构约定：标准答案都在仓库原文件中，用户在练习时复制出同名文件并添加 `copy` 后缀进行还原练习
- 支持一次处理多个文件，批量对比 review
- 技能只负责对比分析，不修改原有代码
- 不支持没有标准答案的题目评价

## 质量标准
- 必须正确识别所有匹配的文件对，不能遗漏
- 对比分析必须覆盖所有要求的维度
- 必须严格遵循评价标准进行判定，结果客观准确
- 输出必须符合报告模板的格式要求
- 必须识别出用户解答中的 bug 和边界问题
- 优化建议必须合理可行
